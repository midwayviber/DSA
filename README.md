# Exam Schedule, Topics, and Certifications

## 1. Exam Schedule
- *Monday*:
  - *Morning*: Second attempt for aptitude test.
  - *Afternoon*: Level 2 exam.
- *Tuesday*:
  - *Morning*: Second attempt for another assessment.
  - *Afternoon*: Level 3 exam.
  - Note: If Level 2 and Level 3 exams go well, attendance on Wednesday is not required.
- *Wednesday*:
  - *Morning*: Third attempt, if needed.
  - *Afternoon*: Optional internal exam for additional preparation.

---

## 2. Level-Specific Topics

- *Level 2*:
  - *Concepts*:
    - Advanced knowledge of *arrays, **strings, **Standard Template Library (STL)* in C++, *hash maps, dictionaries, and **object-oriented programming (OOP)*.
  - *Coding Questions*:
    - Topics include strings, arrays (e.g., brute-force solutions without TLE), sum of arrays, character occurrences, and subarrays.
  - *MCQs*:
    - Covers OOP (8-9 questions), STL (20 questions), and arrays and strings.

- *Level 3*:
  - *Concepts*:
    - Basic data structures like *stacks, **queues, and **linked lists* (e.g., adding nodes).
  - *Coding Questions*:
    - Focuses on arrays, strings, stacks, queues, and linked lists.

---

- Red Hat and CCNA certifications are *not required*.
